# Everything Boss

**すべてのアイテム (NBT 込み) をボスにする** Minecraft Forge 1.20.1 用 Mod。
1.21.1 (NeoForge) 版は `1.21.1` ブランチにある。

ボスの本体は、回転する立方体の枠の中で 3 ブロック幅に引き伸ばされたアイテムそのもの。
ビームも弾もそのアイテムの描画で表現される。枠やビームの色はアイテムのテクスチャから自動で決まる。

## 遊び方

### 祭壇 (サバイバル)

1. 祭壇にアイテムを持って右クリック → 捧げ物として祭壇の上に浮く (1 個消費)
2. 素手で右クリック → 儀式が始まり、4 秒後に落雷とともにボスが現れる
3. 儀式の前なら、スニーク + 素手で捧げ物を取り戻せる (オフハンドに盾などを持ったままでもよい)

祭壇の種類で難易度とドロップが変わる。ドロップはボスのアイテムを **NBT ごと複製** したもの。
ドロップと経験値は、倒れたボスが爆散するときにまとめて飛び散る。

| 祭壇 | 難易度 | HP | 攻撃 | 技の間隔 | ドロップ | 経験値 |
|---|---|---|---|---|---|---|
| 石の祭壇 | かんたん | ×0.6 | ×0.6 | 長め | 2 個 | ×0.5 |
| 金の祭壇 | ふつう | ×1 | ×1 | 普通 | 4 個 | ×1 |
| ダイヤモンドの祭壇 | むずかしい | ×1.8 | ×1.4 | 短め | 16 個 | ×2 |
| ネザライトの祭壇 | 悪夢 | ×3 | ×2 | かなり短い | 64 個 | ×4 |

上位の祭壇はひとつ下の祭壇から作る。材料を手に入れるとレシピ本に載る。

| 祭壇 | 材料 |
|---|---|
| 石 | 石レンガ ×5 + アメジストの欠片 |
| 金 | 金インゴット ×4 + エンダーアイ + 石の祭壇 |
| ダイヤモンド | ダイヤモンド ×4 + エンダーアイ + 金の祭壇 |
| ネザライト | ネザライトインゴット ×4 + ネザースター + ダイヤモンドの祭壇 |

### コマンド (権限レベル 2)

- `/itemboss summon <アイテム{NBT}> [座標]` — 指定したアイテムのボスを召喚
- `/itemboss hand [座標]` — メインハンドのアイテムのボスを召喚
- `/itemboss attack <ボス> <技名>` — 技を強制発動 (確認・マップ制作用)

## ボス

- **ステータス**: HP はレア度とエンチャントで増える。武器・防具はその攻撃力・防御力から、
  それ以外のアイテムはアイテム ID から決まる片側正規分布で攻撃力・防御力が決まる
  (たいていは控えめだが、ときどき飛び抜けて強いアイテムがある)
- **登場・変身**: 登場時と HP 50% での変身 (発狂) の演出中は無敵
- **1 発の上限**: 1 回の攻撃で削れるのは最大 HP の 50% まで (設定で変更可)
- **人数**: 登場したとき近く (48 ブロック以内) にいるプレイヤーが 2 人以上なら、1 人増えるごとに HP が 50% 増える (設定で変更可)

### 技

| 技 | 内容 |
|---|---|
| 薙ぎ払い | 振りかぶってから全周を一回転で薙ぐ |
| 突進 | 切っ先を向けて錐揉みで突っ込む |
| ビーム | 予告線 → 照準固定 → アイテムを引き伸ばしたビームでゆっくり追尾 |
| 連射 | アイテムの複製を扇状に撃つ |
| アイテムの雨 (発狂) | 頭上からアイテムが降る |
| 叩きつけ (発狂) | 浮き上がって落下、衝撃波 |
| 急降下ビーム | 上空からビームで狙い続けながら頭上を突き抜ける |
| 回転ビーム + 弾幕 (発狂) | ビームで地面に輪を描きながら全方位へ弾を撃つ |
| 三連突進 → 薙ぎ払い | 狙い直しながら 3 回突進し、薙ぎ払いで締める |
| 照準付き叩きつけ (発狂) | 真下への予告線で着地点を示し、着地で放射状に 2 波撃つ |

### アイテムの性質

ボスの戦い方はアイテムによっても変わる。

| 性質 | 当てはまるアイテムの例 | 効果 |
|---|---|---|
| 炎 | ブレイズロッド、溶岩入りバケツ、松明、火属性・フレイムのエンチャント | 攻撃が当たると燃える |
| 氷 | 雪玉、氷、粉雪入りバケツ、氷渡りのエンチャント | 攻撃が当たると凍えて鈍くなる |
| ウィザー | ウィザーローズ、ウィザースケルトンの頭蓋骨、ネザースター | 攻撃が当たるとウィザー状態になる |
| 爆発 | TNT、火薬、エンドクリスタル、ロケット花火 | 弾が着弾で爆ぜる (地形と落ちているアイテムは壊さない) |
| エンダー | エンダーパール、コーラスフルーツ、シュルカーの殻 | ときどき相手の近くへ瞬間移動する |
| ノックバック | ピストン、スライムボール、ノックバック・パンチのエンチャント | 吹き飛ばしが強くなる |
| 棘 | サボテン、スイートベリー、鍾乳石、棘のエンチャント | 近接攻撃を受けるとダメージを返す |

ポーション、効果付きの矢、怪しいシチュー、効果の付く食べ物 (フグ、毒のあるジャガイモなど) は、
その効果を使う。有害な効果は攻撃を当てた相手に短く掛かり、有益な効果は登場時にボス自身に掛かる。
力のポーションのボスは力が強く、エンチャントされた金のリンゴのボスは再生と耐性を持って現れる。

どのアイテムがどの性質を持つかは、アイテムタグとエンチャントタグ `everythingboss:traits/<名前>` で決まる
(`fire` `frost` `wither` `explosive` `ender` `knockback` `thorns`)。データパックで足したり外したりできる。

### 捧げられないアイテム

アイテムタグ `everythingboss:cannot_offer` に入っているアイテムは祭壇に捧げられない。既定では空。
中身ごと複製される収納アイテム (シュルカーボックスや他 Mod のバックパックなど) を止めたいサーバーや
Mod パックは、データパックでここに足す。

## 設定 (`config/everythingboss-common.toml`)

| 項目 | 既定値 | 内容 |
|---|---|---|
| `baseHealth` | 300 | 倍率を掛ける前の基本 HP |
| `damageMultiplier` | 1.0 | ボスの全攻撃に掛かる倍率 |
| `maxDamagePerHit` | 0.5 | 1 発で削れる最大 HP の割合 |
| `dropItemOnDeath` | false | コマンドで呼んだボスがアイテムを 1 個落とすか (祭壇のボスは難易度に従う) |
| `experience` | 200 | 経験値 (祭壇のボスは難易度の倍率が掛かる) |
| `healthPerExtraPlayer` | 0.5 | 2 人目から 1 人増えるごとに足す HP の割合 |
| `itemTraits` | true | アイテムの性質 (炎・ポーションの効果など) を使うか |

## ビルド

```
./gradlew build
```
